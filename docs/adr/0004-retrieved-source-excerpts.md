# ADR-0004：原文使用本地检索摘录而非整书提示词

- 状态：已采纳
- 日期：2026-08-11

## 背景

小说原文通常为数 MB。每轮把全文放入模型上下文既不可行，也会显著增加 token、延迟和费用。完全依赖模型预训练记忆又容易产生原作事实错误和角色越权知情。

## 决策

原文与结构化 `original_knowledge` 保存在本地，构建可缓存的检索数据。每轮根据输入、参与角色和场景检索少量相关条目；PromptBuilder 再限制条目数量和摘录长度，并携带可见角色等知识边界。

相同原文上传使用内容摘要复用已有文件，避免为重新蒸馏产生重复副本。

## 结果

优点：

- 本地读取不消耗模型 token；
- 模型只接收与当前轮次相关的短证据；
- 原作证据优先于模型模糊记忆；
- 可为不同角色限制可见证据。

代价：

- 检索召回不足时可能遗漏相关事实；
- 需要维护索引缓存和失效逻辑；
- 摘录必须防止泄露过长受版权保护内容。

## 约束

提示词不得声称注入了未检索到的原作事实。诊断信息可记录命中数和摘录字符数，但不能记录整书或无限制摘录。
