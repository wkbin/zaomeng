# 造梦 v2.1.1

v2.1.1 重点提升了人物蒸馏、模型兼容性、长期记忆和对话流式体验，并补齐了原文证据与质量管理能力。该版本可从 v2.0.0 直接覆盖升级；重要书卷仍建议在升级前导出备份。

## 重点更新

- **蒸馏自动修复与补全**：自动检查人物档案的空字段、模板化重复和自相矛盾，只针对问题字段重新检索证据并修复，不再重写整份人物卡。
- **多人蒸馏质量提升**：采样预算会随所选人物数量增长，支持一次处理多名人物；增量蒸馏也可同时选择多个人物，不再限制为单人推进。
- **更可靠的人物档案**：未知字段保持真正空白，不再写入“留空”或“证据不足”；加强字段规范化、证据覆盖率和质量检测，降低低完整度与虚构补全。
- **原文证据中心**：支持搜索原文片段、查看位置、调整角色知识边界、固定关键证据，并查看回复实际命中的摘录。正常对话界面不再直接展示证据，避免影响阅读观感。
- **模型能力检测中心**：一键检测首字符时间、完整耗时、真实流式、SSE 分块、JSON/NDJSON 遵循率、`response_format`、推理开关和 token 参数，并生成推荐配置。
- **长期记忆质量管理**：区分自动记忆和固定记忆，显示来源轮次，支持合并重复记忆、标记过期或冲突，以及查看本轮命中的记忆。
- **对话流式与结构化输出增强**：对话回复采用更适合增量解析的结构化流，强化 JSON/NDJSON 约束与异常恢复，减少“已显示后撤回”和纯文本格式漂移。

## 体验与功能

- 设置页新增项目官网与支持入口。
- 新增项目官网和 GitHub Pages 页面，适配手机与桌面展示。
- 插件执行边界进一步收紧，避免插件越权影响核心流程。
- Android 返回手势与页面返回处理更加稳定。

## 稳定性与架构

- KMP 工程拆分为 `core:contracts`、`core:runtime`、`core:domain` 和 `data:remote`，降低共享 UI、服务端契约与网络实现之间的耦合。
- 将会话创建、失败恢复和删除确认等业务编排从 ViewModel 下沉到 UseCase，并补充领域测试。
- 统一并升级 Kotlin、Ktor、Compose、AndroidX 等依赖，调整 Android SDK 配置。
- 加强蒸馏、对话解析、模型请求、记忆质量、原文证据、插件和会话状态测试。
- 修复模型连续返回同一人物时出现多个临时气泡、完成后又合并成超长消息的问题。
- 修复多人蒸馏触发 token 上限后无法继续的问题：续跑保留已完成人物和完整计划，并在输出截断时改用紧凑约束重新生成。
- 补充 Ktor Server API、架构说明、安全策略和贡献指南。

## 升级说明

- 从 v2.0.0 升级无需额外数据迁移，可直接覆盖安装。
- 从旧版 Android 1.5.0 及更早版本升级时，仍需先在旧版导出 `.zaomeng-run.zip` 书卷包，再在新版本中导入。
- iOS 仍处于预览阶段，推荐优先使用 Android 或 Desktop 版本。
