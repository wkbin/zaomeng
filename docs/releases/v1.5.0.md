# 造梦 v1.5.0

这一版本重点增强了互动剧情的临场感、原作一致性和 Android 聊天体验。剧情现在可以自然引入临时 NPC，插件可以直接参与剧情推进，聊天恢复与流式输出也更加稳定。

## 主要更新

### 临时 NPC 正式加入剧情

- 单人会话和群聊都可以根据剧情需要临时引入 NPC。
- NPC 不再只是旁白中的文字提示，而会成为当前会话中的实际在场角色，可以发言、被 `@`、继续互动，并在离场前保持上下文。
- 临时 NPC 仅属于当前会话，不会污染作品的正式人物库、长期关系网或原作角色资料。
- 新增内置“随机临时 NPC”插件，可按当前场景生成适合介入剧情的路人、店员、守卫等角色。

### 新增剧情骰子插件

- 加入由模型驱动的“剧情骰子”内置插件。
- 可在需要转折、冲突或意外事件时生成符合当前场景和人物关系的推进结果。
- 插件结果会遵守当前剧情状态，不会把无关设定强行写入主线。

### 原作知识约束

- 对话生成会动态检索原作内容，为人物回应补充可追溯的原作依据。
- 增强角色知识边界，减少角色提前知道秘密、跨场景获取信息或凭空补写原作事实的问题。
- 优化人物档案中的占位内容识别与修复，降低空泛设定进入正式人物资料的概率。

### Android 聊天体验

- 支持为聊天设置本地背景图片，并调整背景可见度和模糊程度。
- 聊天背景覆盖消息区、顶部导航栏和底部输入区；顶部与底部带有半透明遮罩，确保按钮和文字清晰。
- “聊天显示”设置拆分为字号与密度、聊天背景、模型推理三个分组，并提供背景效果实时预览。
- 改进会话恢复：应用切换、连接中断或发送结果未知时，可以更可靠地恢复或核对当前回合。
- 模型推理内容支持流式展示，并默认关闭，可在设置中按需开启。
- 优化模型档案编辑页的底部安全区域，避免操作按钮被系统导航栏遮挡。

## 稳定性改进

- 修复流式响应中的 UTF-8 解码问题，减少中文输出乱码或被截断的情况。
- 增强模型请求重试、流式事件解析和异常恢复逻辑。
- 加固临时 NPC 的会话登记、在场状态、分支恢复和一致性检查。
- 精简 Android 内置 Web 运行时资源，减小无关内容对安装包和启动过程的影响。
- 更新部分 Android Compose API，提升新版本 Android 与构建工具的兼容性。

## 升级说明

- Android 版本号升级至 `1.5.0`，`versionCode` 为 `7`。
- 现有作品、人物档案和聊天会话可以继续使用，无需手动迁移。
- 聊天背景为设备本地设置，不会上传到作品数据或同步到其他设备。
- 模型推理显示默认关闭，升级后可在“设置 -> 聊天显示”中开启。
