# 造梦 v2.0.0

> ⚠️ **升级提示（重要）**：2.0.0 与旧版 Android（1.5.0 及更早）数据不兼容，本地数据不会自动迁移。**升级前请先在旧版中导出书卷包（`.zaomeng-run.zip`）备份**，安装 2.0.0 后通过“导入书卷包”恢复。

2.0.0 是一次架构重写版：底层由旧式内嵌运行时整体迁移到 **Kotlin Multiplatform（KMP）**，Android、桌面、iOS 三端共享同一套 Compose UI 与业务逻辑，后端统一为 Ktor + Room。这一版的核心目标是换一个新地基，而不是堆功能——核心链路完整保留，同时打开桌面与 iOS 两个新平台。

## 新平台

- **桌面端（Windows / macOS / Linux）**：自适应平板式布局、系统托盘通知、剪贴板分享、头像裁剪支持按钮与滚轮缩放、窗口标题栏跟随深浅主题、启动时检查更新（跳转下载页）。
- **iOS**：全新目标平台（Xcode 工程 + 共享 framework）。

## 新增功能

- **在线书库**：浏览并下载社区书卷包。
- **世界时间线 / 故事回顾**：查看世界记忆时间线与故事进展回顾。
- **会话自动标题**：创建会话后按内容自动生成标题。
- **主题增强**：深浅色之外支持多种主题模式与动态取色。
- **可预测返回**：设置开关（默认关闭），参考 KernelSU 交互。
- **头像裁剪**：按钮与滚轮缩放，桌面与手机一致。

## 保留的核心功能

- 书卷：导入（TXT / EPUB / 书卷包）、蒸馏、增量蒸馏、停止与重跑、流式导出。
- 人物：资料校对、质量报告、AI 补全、头像、关系图谱与冲突提示。
- 会话与聊天：SSE 流式、断线恢复、分支、@ 提及、读心（内心独白）、群聊与旁观、临时 NPC、剧情骰子、高级导演工具。
- 卡库：场景卡 / 自设卡 / 开局模板。
- 插件：内置插件与插件管理。
- 设置：模型配置、字号与紧凑模式、聊天背景、应用更新。

## 功能边界

- 核心链路完整；部分边缘视图（如高级会话状态的部分可视化）暂未迁移，后续版本补齐。
- 按产品决策移除 WebUI 专属的“内置书卷试玩 / 一键发布内置书卷”功能。
- Python 后端与 WebUI **不再维护**，仅作为行为对照与测试基线。
- iOS 为首版预览，建议以 Android / 桌面为主要使用平台。

## 稳定性与基础

- 数据统一迁入 Room（SQLite），书卷 / 会话 / 消息 / 卡片 / 人物等实体化存储，Paging 分页。
- 提示词统一为 composeResources 资源，三端共用同一套 YAML。
- 构建与测试：Android / 桌面 / iOS 编译纳入 CI，Kotlin 与 Python 测试保持绿色。
