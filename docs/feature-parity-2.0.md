# 1.5.0 → 2.0.0 功能对照清单

> 用途：发布 2.0.0 前核对功能差集。对照对象：1.5.0 Android 已实现功能 vs 2.0.0 KMP 客户端（Android / 桌面 / iOS）。

## 结论摘要

- **核心链路全部保留**：书卷（导入/蒸馏/导出）、人物、关系、会话、聊天（流式/分支/读心/群聊旁观）、卡片、插件。
- **明确移除**：内置书卷试玩 / 一键发布 `builtin_novels`（按产品决策）；WebUI 专属工作流与远程模式（平台不同，WebUI 不再维护）。
- **2.0 新增**：桌面端、在线书库、世界时间线/故事回顾、会话自动标题、主题 6 模式+动态取色、可预测返回、头像裁剪、桌面托盘/剪贴板。
- **待核实**：高级会话状态中“人物状态弧线/发言节奏/近期事件信号”的客户端视图；拍点成熟自动浮出下一幕。
- **未验证**：iOS 平台从未实际运行。

## 发布前建议

1. iOS 至少跑通模拟器一次，否则 2.0 发布说明中“三端”表述改为“Android + 桌面为主，iOS 预览”。
2. 补齐或明确标注“待核实”项（分支图可视化、状态弧线/发言节奏等）。
3. 发布说明中写明功能边界：核心链路完整，WebUI 专属功能移除，部分边缘视图暂未迁移。
