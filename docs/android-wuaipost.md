## 软件名称

造梦 Android

## 软件版本

`v1.5.0`

## 软件简介

造梦是一套面向中文小说人物的 AI 整理与互动工具。

它可以把小说正文整理为结构化人物资料和人物关系图谱，再让角色按照自己的性格、立场、关系和记忆进入场景互动。安卓端将服务直接打包进 APK，书卷、人物资料和会话记录保存在手机 App 私有目录中，不需要自己部署服务器。

简单来说：把小说导入手机，配置一个兼容接口的模型，就可以在手机上整理人物、查看关系，并和角色聊天。

## 主要功能

### 1. 小说导入

- 支持 UTF-8、UTF-16、GB18030 编码的 TXT 小说
- 支持从未加密 EPUB 中提取正文
- 支持导入和恢复 `.zaomeng-run.zip` 书卷包
- 可以先保存书卷，稍后配置模型后再开始蒸馏

### 2. 人物蒸馏

从小说正文中整理可复用的人物资料，包括：

- 身份、动机和性格底色
- 说话风格与决策逻辑
- 情绪触发点和关键羁绊
- 记忆线索与人物弧光

长篇小说会自动分批处理，并在界面和通知栏显示进度。任务中断后，下次启动可以继续处理未完成部分。

### 3. 人物关系图谱

可以查看和校对人物之间的关系，包括关系类型、信任/依赖/冲突等数值、关系变化、冲突点和典型互动。

### 4. 三种互动模式

- `act`：代入小说中的某个角色发言
- `insert`：以自己的身份进入小说场景，与角色互动
- `observe`：不参与发言，观察多个角色自行展开对话

聊天支持流式回复、消息搜索与复制、重新生成、从消息处分支、人物 `@` 提及、回到底部、新消息提示，以及可调字号和紧凑显示。

### 5. 可复用创作卡片

支持创建和复用：

- 场景卡
- 自设卡
- 开场模板

创建会话时可以直接选择卡片，也可以在聊天过程中切换场景或使用系统推荐的下一幕。

### 6. 本地书架与数据流转

- 书卷、人物资料和会话记录保存在 App 私有目录
- 支持导出 `.zaomeng-run.zip`，方便备份或迁移
- 支持从在线书卷库下载已整理好的书卷包
- 应用内可检查 GitHub Release 中的正式版更新

## 安装与使用

1. 下载 APK 并安装。
2. 首次打开后进入“模型设置”。
3. 选择支持的模型服务商，填写模型名称和 API Key；也支持自定义兼容接口。
4. 在书架中导入 TXT、EPUB 或书卷包。
5. 导入小说后开始人物蒸馏，等待任务完成。
6. 打开人物资料、关系图谱，或新建会话开始互动。

## 使用说明与限制

- 当前发布包仅包含 `arm64-v8a`，适用于主流 64 位安卓真机，不包含 `x86_64` 模拟器运行时。
- 最低支持 Android 7.0（API 24）。
- TXT 文件最大支持 24 MB，压缩书卷包最大支持 64 MB。
- EPUB 仅支持未加密 EPUB 的 XHTML/HTML 正文提取，不支持 DRM 或复杂版式还原。
- 人物蒸馏和角色聊天需要调用用户配置的模型服务，会产生对应的模型费用和网络流量。
- App 与内嵌服务之间通过手机本机回环地址通信；模型请求仍会发送到用户配置的模型供应商。
- Android 13 及以上建议允许通知权限，以便查看后台蒸馏进度；拒绝通知不影响前台启动任务。
- 请仅导入和处理自己拥有权利或已获授权的内容，并遵守模型服务商的使用规则。
