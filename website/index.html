第一次使用造梦

从安装到第一句话，
跟着这四步就够了。

不需要会编程。先准备一个兼容的 AI 模型服务，再导入小说、等待人物蒸馏完成，就可以创建多角色会话。

  1. 01
    下载与安装

    先把造梦装到设备上

    Android 用户下载 APK；Windows、macOS 和 Linux 用户下载对应的桌面版本。安装完成后直接打开应用。

    GitHub Releases→选择你的平台→安装并打开
    前往下载 ↗
  2. 02
    首次必做

    连接一个 AI 模型

    蒸馏人物和聊天都需要模型。进入模型设置，选择服务商预设和模型，填写服务商提供的 API Key；本地 Ollama 通常不需要 Key。

    书卷架→模型设置→新增模型档案
    填好后先点 测试连接；成功后点 创建并启用。API Key 保存在设备的安全存储中。
  3. 03
    建立书卷

    导入小说并开始蒸馏

    选择 TXT 或 EPUB 小说，填写想提取的人物名，保留“建立后立即蒸馏”。应用会先显示预计调用次数、Token 和耗时。

    书卷架→导入小说→TXT / EPUB 小说→确认开始
    人物名可用逗号、分号或换行分隔。第一次建议只选 2–4 位主要人物，速度更快，也更容易检查结果。
  4. 04
    开始对话

    选择人物，进入场景

    等书卷出现“人物资料和关系已经整理完成”，新建会话，选择书卷、你的身份和出场人物；场景卡可以暂时不选。

    本卷会话→开始一段新会话→出场人物→进入场景
    旁观 人物自行推进 扮演 代入书中人物 入场 以自己的身份加入
最省事的体验方式

先从在线书卷包开始

不想第一次就等待蒸馏？在“导入小说”里打开“在线书卷包”，下载一份已经处理好的书卷，再直接创建会话。

聊天仍需要先配置模型。

先认识三个词

书卷
一部小说的正文、人物、关系和记忆集合。
蒸馏
让模型从小说中整理人物资料和关系。
模型档案
你所使用的 AI 服务、模型和连接信息。

遇到问题？

导入后为什么不能聊天？

至少要有一位人物完成蒸馏。打开书卷查看进度，看到人物资料后再新建会话。

模型连接失败怎么办？

检查服务商、模型名称、接口地址和 API Key，然后重新点“测试连接”。

蒸馏可以退出页面吗？

可以。启用立即蒸馏后任务会在后台继续，进度会保存在本机。
